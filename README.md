# Portfólio Lorran Daniel

Pacote do site estático para GitHub Pages.

Extraia este ZIP e envie seu conteúdo à raiz do repositório: index.html deve ficar diretamente na raiz, ao lado de css/, js/, img/, certificados/, curriculos/ e projetos/.

Em Settings > Pages, selecione Deploy from a branch, a branch usada no envio e /(root). O .nojekyll já está incluído.

Para a prévia local, execute python preview_portfolio.py e abra http://127.0.0.1:8021/index.html?lang=pt.

Este pacote contém somente o site público e a ferramenta de prévia local. A aplicação FastAPI e seus dados não fazem parte desta publicação estática. O backup completo do projeto está separado.

Documentação oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
